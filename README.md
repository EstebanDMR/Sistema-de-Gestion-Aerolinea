# Sistema de Gestión de Aerolínea

Proyecto de análisis de datos sobre la operación de una aerolínea. Se diseñó una base de datos relacional en MySQL, se generaron datos de prueba y se desarrolló un dashboard en Power BI para explorar la información y obtener indicadores operativos.

## Herramientas

- MySQL
- Python
- Power BI

## Contenido

- Scripts SQL para crear, poblar y validar la base de datos.
- Script en Python para generar datos.
- Dashboard de Power BI.
- Diagrama entidad-relación y modelo relacional.
